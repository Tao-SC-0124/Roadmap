## 3. 关键裁决

| 事项 | 裁决 |
| --- | --- |
| 均线 MA5／MA10 | **不再作准入门槛**（生菜 2026-11-04）。准入只剩三条：未确认杀逻辑、B≥3、C≥3、B＋C≥7。均线只作行情事实记录。 |
| 赔率锚点 | 分子分母两侧都取「日线最近一次被量能测试过的位置」；B 栏六字段；写不出测试记录→B「未取得」、不生成总分。量化判据默认用 checklist §26 的过渡口径（1.5×、≥1次），可切 `strict`（1.2×、≥2次）。 |
| 先验概率 | 已删除，不进卡；旧提示词的「先验概率必须展示」作废。 |
| 出报告 vs 跟踪 | **分离**。本 skill 不维护长期跟踪、take/pass 状态或持仓；只保留中性状态行与可选的 take/pass 表态请求，供外部机制消费。 |
| 按需推卡 | 不设固定时间；用户要求时跑 1 张；日期目录已有则用、没有则建；同日多次请求不重复；不为凑数降低准入。 |
| GitHub 金融日历 | **已取消**（用户 2026-11-10 明确）。不再读取任何外部金融日历仓库；只按沪深交易所公告核对交易日与 90 天窗口。 |
| daily_push 筛选 | **60／120／250 交易日跌幅榜 × 90 天 S/A 级现象级节点共振**（用户 2026-11-10 确认）。区间涨跌幅＋最大回撤一起算；节点质量优先；无 S/A 节点不出卡；排序＝节点质量＞跌幅可解释/可剥离＞B/C＞纯度。 |
| 无合格标的 | 首次请求：`本轮全市场未检索到符合准入的产业敞口。`＋最多 3 个最接近的被否决候选；同日重复请求且无新增：`本轮未检索到新的符合准入产业敞口。` 默认不打「暂无」静默。 |
| 历史样本 | 实际收到 3 份满意卡，不是 10 份；只作版式参考，禁止复制数字/结论/评分/锚点。 |
| 三美母版 | 已找到：`信息卡/Version2.2/制冷剂-三美股份-产业信息卡-Version2.2-2026-11-02.html`。skill 骨架与历史卡同源；若要完全对齐，可用母版 CSS 替换骨架 CSS。 |
| 大节点卡 | 是另一种卡型，不属于本技能流程，只作可选参考。 |

1. 上传 `dist/industry-exposure-card-skill-v2.3.0.zip`。

## 11. 按需推卡（2026-11-12）

- `daily_push` 不再规定 08:00／09:00／10:00；用户要求时运行，每次最多 1 张卡。
- 日期目录：优先用用户已 init 的 `正式卡/YYYYMMDD/` 或 `正式卡/YYYY-MM-DD/`；都没有则自动创建 `正式卡/YYYYMMDD/`。
- 同日可多次请求，但不得重复同一「敞口＋主标的」；无新增时如实报告「本轮未检索到新的符合准入产业敞口」。
- 旧三班只作可选调度，不是默认规则。

## 3. 关键裁决

| 事项 | 裁决 |
| --- | --- |
| 均线 MA5／MA10 | **不再作准入门槛**（生菜 2026-11-04）。准入只剩三条：未确认杀逻辑、B≥3、C≥3、B＋C≥7。均线只作行情事实记录。 |
| 赔率锚点 | 分子分母两侧都取「日线最近一次被量能测试过的位置」；B 栏六字段；写不出测试记录→B「未取得」、不生成总分。量化判据默认用 checklist §26 的过渡口径（1.5×、≥1次），可切 `strict`（1.2×、≥2次）。 |
| 先验概率 | 已删除，不进卡；旧提示词的「先验概率必须展示」作废。 |
| 出报告 vs 跟踪 | **分离**。本 skill 不维护长期跟踪、take/pass 状态或持仓；只保留中性状态行与可选的 take/pass 表态请求，供外部机制消费。 |
| 每天三班 | 08:00 主扫描、09:00 增量、10:00 增量；每次最多 1 张，合计最多 3 张；不为凑数降低准入。 |
| GitHub 金融日历 | **已取消**（用户 2026-11-10 明确）。不再读取任何外部金融日历仓库；只按沪深交易所公告核对交易日与 90 天窗口。 |
| daily_push 筛选 | **60／120／250 交易日跌幅榜 × 90 天 S/A 级现象级节点共振**（用户 2026-11-10 确认）。区间涨跌幅＋最大回撤一起算；节点质量优先；无 S/A 节点不出卡；排序＝节点质量＞跌幅可解释/可剥离＞B/C＞纯度。 |
| 无合格标的 | 08:00：`本轮全市场未检索到符合准入的产业敞口。`＋最多 3 个最接近的被否决候选；09:00／10:00：`本轮全市场未检索到新的符合准入产业敞口。` 默认不打「暂无」静默。 |
| 历史样本 | 实际收到 3 份满意卡，不是 10 份；只作版式参考，禁止复制数字/结论/评分/锚点。 |
| 三美母版 | 已找到：`信息卡/Version2.2/制冷剂-三美股份-产业信息卡-Version2.2-2026-11-02.html`。skill 骨架与历史卡同源；若要完全对齐，可用母版 CSS 替换骨架 CSS。 |
| 大节点卡 | 是另一种卡型，不属于每日本技能流程，只作可选参考。 |

## 5. 已知缺口

1. **历史样本只有 3 份**，不是 10 份；若还有 7 份，放入 `skill/assets/examples/` 后重新打包即可。
2. **三美 2.2 视觉母版已找到**：在 `信息卡/Version2.2/制冷剂-三美股份-产业信息卡-Version2.2-2026-11-02.html`。当前 skill 骨架与历史卡同源；若要完全对齐母版，可用母版 CSS 替换骨架 CSS。
3. **登海种业卡有模板注释**，不能作为“零注释”交付样本；它只用于看版式。
4. **Workbuddy 的定时任务能力**我无法实测；`references/workbuddy-setup.md` 给了三个班次的提示词，若平台字段名不同，按语义对应。
5. **实时行情/公告接口**取决于你的 Workbuddy 环境；无网络时按「未取得」处理，不会编数。

## 6. 建议的上线步骤

1. 上传 `dist/industry-exposure-card-skill-v2.3.0.zip`。
2. 在 Skill 管理页确认 `SKILL.md`、`references/`、`assets/skeleton-template.html` 可见。
3. 建 08:00／09:00／10:00 三个定时任务，提示词直接复制 `references/workbuddy-setup.md` §3。
4. 先手动跑一次 08:00，检查：HTML 能打开、`{{` 为 0、推送正文≤5 行、无合格时文案正确。
5. 同一天跑 09:00／10:00，确认不重复标的。
6. 连续跑 2—3 天，用 `scripts/validate_card.py` 抽查，重点看锚点、政策标签、纯度、去重。

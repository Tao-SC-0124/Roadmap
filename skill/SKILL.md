# 产业信息卡 V3.0

从一条可能实质改变盈利或估值预期的新传入信息起笔，用事前基线识别增量，再找它改变哪些 A 股敞口的交易价值。扩产、严重断供或订单变化都可成为起点。市场是否已经认可单独记录，有证据的消息可以早于盘面反应。正文顺序为新信息概述、三维评分与准入、历史可比事件、A 股相关公司。

1. **写准新闻和方向。** 用陈述式标题交代主体、动作和直接对象。一至两句说明新增事实、相较事前基线的变化与关键限制。明确谁的量、价、成本或利润会变，偏多、偏空或分化都用同一证据要求，有缺口就写条件。原件区分草案、公示、发布及生效，标明日期和时区。
2. **做事件准入。** 预期差大小、影响规模、利润传导机制顺畅程度各 0–5 分，等权。按 [事件取证与评分](references/research-paths.md) 给每项分数和一句依据。每项至少 3 分且合计至少 11 分才准入。关键依据尚缺或存在堵点时标「未准入」，直写缺口。未准入卡可交代新闻、历史证据与条件性关联。
3. **先对照历史。** 逐项检查用户给出的历史案例，补充有机制关联的遗漏案例。用一行写清日期、原始冲击、可核实的同期领涨或分化、映射到本次的逻辑与边界。行情结论保留区间和出处。只证实个股涨跌时，按可核实的表现描述。
4. **再列公司。** 写公司、代码、业务概览、行业地位、**新信息共振敞口**和并行敞口。共振来自历史机制与本次新增利润路径，技术适配和新增订单分别写清。优先纳入同敞口有行业地位或市场辨识度的标的，地位以可核实的角色、份额或同窗表现表述。叠加题材、量能拥挤与同波段指标股若有证据并影响归因，就在相关行内写一句事实。涉及 T+1、放量与回落时保留对应交易时点和口径。
5. **仅在必要处加标签。** 政策对该敞口获利前提有实质制约时标「政策依赖高」。技术替代、商业化或客户切换有实质进展且改变该敞口判断时标「技术迭代」。
6. **每家公司两句口语。** 一句话路演用公司的第一人称，解释为什么同敞口里值得先看我，写已有能力和本次能承接的条件。没有正向承接证据时，讲清我对应哪种敞口、为什么同类强项不能填补本次缺口。一句话风险说最容易让主张失败、让交易受到大损失的具体原因和后果，用「要是……就……」等自然表达。两句转述该行出处支持的事实和情景，避免捏造公司引语、赢面或承诺。

页面呈现上述四部分及原始出处。版式只保留可用于判断的事实、分数和关联。研究笔记、旧版复盘、盘面评级、预设观察期限及日历留在卡面之外。原事项出现有来源的实质进展时，用新的新闻卡交代变化并重评准入。重复报道归回既有事件。

## HTML 交付

读 [数据字段与页面验收](references/html.md)，从 [数据样例](assets/case.example.json) 开始，使用配套 [模板](assets/card-template.html) 生成单文件 HTML。交付前查评分口径、事实与出处，并检查窄屏和来源跳转。

```sh
python3 scripts/render_card.py <研究数据.json> <产业信息卡.html>
```

## A4 打印副本

用户需要打印时，用同一份已核验的 HTML 生成 A4 PDF。第一页呈现新信息、评分与历史对照，路演公司从第二页开始。正式工作区输出到 `待打印PDF/YYYYMMDD/`。命令、依赖和验收见 [A4 打印](references/printing.md)。

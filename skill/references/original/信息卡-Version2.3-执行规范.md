## 1. 任务与边界

投资原则：**持有具备安全边际的高成长股，并通过波段操作平滑收益。** 允许明确区分的事件型机会。

领航员负责敞口定义、证据搜集、纯度估计、下跌归因、未来节点、评分及比较；操盘手负责技术核验、仓位、交易和退出。报告是一份可快速扫读的路书，不是资料堆积。

- 每个敞口仅交付一个独立HTML，包含主标的、同敞口公司、评分、节点、成长、下行参照与来源。
- 两种模式：`named_research`（用户点名个股或敞口；可研究不合格样本，但不得称已入池）与`daily_push`（按需推卡：用户要求时运行；每次最多1张；必须先过§2.5的跌幅榜＋S/A节点共振，再过准入三条）。
- 主动推荐必须通过：①未确认杀逻辑；②B≥3且C≥3；③B+C≥7。**MA5／MA10不再是准入门槛**，只可作行情事实记录，不得作为准入、打分、降级或“降为观察”的依据，也不得新设替代性的均线或趋势软门槛。
- daily_push另加候选门槛：候选必须来自60／120／250交易日跌幅榜；90天内至少一个S/A级现象级节点；跌幅与节点共振；无S/A节点、只有C级软节点、或不在跌幅榜的候选不出卡。详见§2.5。
- **出报告与跟踪分离**：本规范只出报告，不维护长期跟踪、take／pass状态或持仓；后续跟踪由外部机制承接。
- **打印副本**：HTML是唯一研究交付；打印PDF是派生物，A4、最多6页、保留原卡图形与配色、不改研究结论；由独立打印流程处理（§10.1）。
- 指定个股可以研究不合格样本，但不能宣称已正式入池。评分达线不代替其他门槛。
- 用户明确修改优先，其次本规范，其次母版视觉；历史案例和旧指令不能覆盖本规范。
- 独立HTML使用内联CSS／原生JS；折叠、试算、证据开关离线工作。不要加外部脚本、自动外发或追踪。

## 2. 先锁定一份“敞口比较约定”

打分和找公司之前，在内部数据中确定以下字段，并在同敞口表前用两句以内概括：

| 字段 | 必须确定的内容 |
| --- | --- |
| 敞口 | 具体产品、业务、环节；列出必须排除的邻近业务 |
| 本次积极变化 | 同一个可观察命题，例如“AI眼镜新增业务继续向公司收入传导” |
| 期间 | 已实现期间、全年预测或年度运行率情景，必须明确是哪一种 |
| 收入口径 | 归属于上市公司合并范围的该敞口收入；分母为公司同期间总营收 |
| 证据口径 | 各公司允许使用同等的直接/间接证据，不能一家公司严、一家公司松 |

**纯度、五关和C必须使用这同一个敞口。** 公司整体数据只能放背景或解释拖累，不得借其他业务的增长给本敞口升级。B仍取公司股价，这是股权投资工具的价格维度，不与业务纯度混算。

例：AI眼镜卡中，歌尔的智能硬件大分部与立讯的消费电子大分部不可直接比较；水晶手机光学的毛利率改善不能算眼镜第五关；立讯汽车和数据中心增长不能算眼镜C4。

### 2.1 开篇先讲产业，再讲主标的

开篇必须包含一个明确命题：`XX敞口未来可能走出（阶段性）景气主升段，核心驱动是XX，成立条件是XX；当前主要矛盾是XX，主标的凭XX承接。`

不能把“未来可能主升”写成没有论据的广告，也不能因模板要求强行看多。证据不足时直接写“目前不足以支持主升判断”及原因；指定研究可以呈现，主动推荐应重新筛选。

观点、主要矛盾和关键经营反向读数均在概述可见。主升指产业景气的研究判断，不承诺股价上涨或兑现日必然落地。

### 2.2 经营下滑必须找原因并进入概述

逐项检查总营收、本敞口收入、销量、实现售价、毛利/吨毛利、归母和扣非；有同比或环比下降时注明指标、范围、期间和比较基准。不能把增速放缓写成绝对下降，不能把销量下降写成营收下降。

对重要下降执行：`下降读数 → 原因 → 对本次主张的影响 → 证据/缺口`。首屏用1—2句交代主要原因；标签不能替代正文解释，细项桥梁放底稿。

原因按量、价、单位成本、产品/客户结构、其他业务、费用、税项及一次性因素检查，只保留与本案有关的因素。区别公告确认、调研/研报归因与研究员推断；不能把转述升级为公司确认。找不到原因，明确“尚未查明”及影响的主张，不编完整故事；若缺口使关键C依据不成立，重评C和推荐资格。

公司整体毛利率不能证明窄敞口吨毛利；毛利率和单位毛利不同，销量下降也不必然使单位毛利下降。税项只解释税后利润，不能解释毛利。累计税额变化不能冒充单季度变化贡献。尽量建立同期间利润桥梁，避免全部经营波动都归结于行业。

### 2.3 从终端市场反推受益公司与利润去向

每份研究必须检索终端产品及主要应用，不能从概念股名单直接开始和结束。内部完成：`主要终端/品牌及份额 → 制造主体 → 有依据的供应链关系 → 本敞口收入/利润承接`。

- 尽量覆盖同口径前5—10家；市场参与者不足或来源仅覆盖五家时按实际，不凑名次。数据不足须说明范围及对公司筛选的影响。
- 份额写清年份/季度、地区、销量或金额、出货或零售、企业或品牌、是否含OEM/ODM。不同口径不拼成完整排名，旧年度不能冒称当年格局。
- 供应关系独立取证，市场大不代表主标的供货多。匿名竞争者可以给有依据的身份推断，但保留原匿名身份、推断标识；不能反过来证明客户订单。
- 多应用行业分开看关键应用，不能用家用空调覆盖汽车、冷链和存量维修。只有与本次主张相关的映射进入正文，长表置03折叠区。
- 必须检索产业链哪个环节更能获取利润：比较相关业务毛利、价差、壁垒、资本投入和竞争结构。不以最高单一毛利率自动认定最优交易，不混公司整体与窄业务、不同期间或投资收益。未取得可比利润率不硬排，给出已有依据及未能确认之处。
- 终端市占率、配额/产能份额、公司收入纯度三者严格分开，不新增到总分。

### 2.4 每份必查技术重要性，条件展示

内部逐项问：现有技术/材料是否有环保、性能、成本或知识产权上限？替代路线是什么？其商业化、政策实施或客户切换已走到哪一步？是否会改变本次敞口需求、利润归属或受益公司？

**触发标准：有可追溯的替代路线进展（商业化、政策或客户切换），且对本次主张、持有展望或公司比较有实质影响。** 纯概念研发、与该敞口无关的技术新闻不触发。记录判定理由和来源，不靠行业名字决定。

- 触发：开篇显示“技术迭代中”，04展开“技术迭代与成长空间”，先解释触发原因再给观点。
- 不触发：不贴标签，不设空技术表；04保持D/E成长空间。技术检查已完成的记录留内部，不给正文增加流程套话。
- 90天以外的技术节点可用于长期路线判断，但不能塞进90天窗口或当作短期催化；未来长期削减不自动否定当前阶段性机会。

### 2.5 daily_push 专有筛选：60/120/250交易日跌幅榜 × 90天S/A级节点共振

`daily_push` 与 `named_research` 的候选来源不同。daily_push不先看涨幅榜、热门板块或概念名单，必须先执行以下顺序：

1. **跌幅榜**：分别取60／120／250**交易日**跌幅榜；逐只算区间收盘涨跌幅＋区间最大回撤；同时算**相对基准跌幅**（个股区间涨跌幅−行业指数同期涨跌幅；行业指数不可用时用沪深300或中证全指并注明），绝对与相对分开列，不用相对跌幅替代绝对跌幅；分窗口排序、不混算；上市不足窗口、停牌、数据缺失写「不存在」，不外推；默认剔除ST／*ST、上市不足窗口、长期停牌、流动性过低。

   **相对跌幅只用于区分“行业普跌”与“个股错杀”**：行业指数优先用申万/同花顺行业指数，不可用时用沪深300或中证全指；同一窗口、同一复权口径；相对跌幅不单独构成准入门槛，也不替代下跌原因分析。
2. **下跌原因**：`下跌读数 → 触发事件 → 杀估值／杀业绩／杀逻辑（主次） → 证据 → 可解释性 → 可剥离性 → 最乐观那天能否定义`。确认杀逻辑淘汰；找不到原因写「尚未查明」，不得编故事。
3. **节点地图**：把90天内节点按S／A／B／C分级。S＝硬节点＋公司专属＋日期确定＋直接改变利润／价格／配额；A＝硬节点＋日期确定＋间接影响，或高确定性软节点＋公司专属订单／价格／客户事件；B＝行业级固定日历数据，只作辅助；C＝一般软节点，只调进度，不作兑现节点。**daily_push至少1个S/A。**
4. **出货窗口四问**：谁付钱？哪个数字变好？为什么节点后市场愿意给更高价？什么结果会让节点失效？答不出，不是现象级。
5. **共振**：至少一个跌幅榜＋S/A节点＋未确认杀逻辑；强共振＝S节点＋B≥4＋C≥4；中共振＝A节点＋B≥3＋C≥3。
6. **排序**：节点质量＞跌幅可解释／可剥离＞B/C＞纯度。两个候选同级时，优先节点更近、日期更硬、桥梁更短的那个。

**没有S/A节点、只有C级软节点、或不在跌幅榜的候选，不出daily_push卡**；最多进内部观察或`named_research`，并标「非daily_push」。

卡片必须多写两行：

- **跌幅读数**：03第一列或06证据写`60/120/250交易日：绝对−x%／−y%／−z%；相对行业或沪深300 −x%／−y%／−z%；区间最大回撤−w%`；不足写「不存在」，不得只写“跌幅较大”。
- **出货窗口**：首屏或01写`YYYY-MM-DD（S/A级节点名称）；谁付钱：…；哪个数字变好：…；节点后更高价的理由：…`。

执行细则、无合格文案、S/A/B/C分级表见 [screening-and-resonance.md](../../skill/references/screening-and-resonance.md)；本规范只保留原则，§12.6做验收。

## 3. 纯度：必须可比，允许有依据的推测

### 3.1 计算与证据

`纯度 = 本公司该敞口可归属收入 ÷ 本公司总营业收入`。

优先使用单列披露；未单列时，用客户、机型、供应关系、出货、单机价值、份额、产线或可追溯调研搭建估计。**不因缺直接披露就停止比较，也不能用相邻大板块代替窄敞口。**

估计至少保留：分子计算、分母、期间、币种/单位、关键参数、各参数属于事实还是假设、来源及日期。一条可追溯间接证据可以支持假设，不设必须几条公告的机械门槛。

常用自上而下模型：`Σ细分出货量 × 公司份额 × 本公司该环节单机收入`。也可以自下而上汇总客户项目；采用其他模型时仍须满足相同边界。

### 3.2 不得省略的约束

- 全表统一产品范围与期间。实际收入、预测收入、潜在产能不能混排成“已实现收入”。
- 全年分子与前三季×4/3分母搭配时，明确称“全年收入情景/年化运行率代理”，不能称真实全年纯度。检查季节性偏差；有可靠全年分母预测则同口径使用。
- 机构A总量与机构B结构比例的定义、期间不一致，不得冒称联合事实。可在情景中显式假设，并说明限制。
- 整机收入已含内部部件时，不再加同公司内部自供收入；外供部分只计合并范围对外交易。
- 联营企业收入不直接并入上市公司营收分子；投资收益与营业收入分开。
- 同一细分的份额相加、客户覆盖范围、单机价值与整机价格不得逻辑冲突。新品尚未量产，不能写成当期已实现收入。
- 不把模型计算结果反过来当作订单、收入或C4的独立证据。
- 年配额、产能许可不等于本期实际对外销售。与九个月收入搭配须估计同期间销量及内供/存货/用途差异，明确参数性质；只变价格的窄情景不覆盖全部误差，不称真实值边界。配额当量与实物吨分别核对。
- 不为满足“必须估计”编造一个无任何业务锚点的比例；先补查、建立有业务边界的宽情景。确实无法形成有意义量级时，报告该参照未完成，不伪称已完成可比排名。

### 3.3 范围、排序与展示

对未披露纯度，给低/中/高三种有明确参数的情景，实际重算范围。不是在一个数字上随意加“±5个百分点”，也不叫统计置信区间。

表面只显示：**公司、代码、中枢百分比、情景范围、业务角色**。中枢约1位小数即可。计算明细统一收进表后的“纯度估算依据”。

按中枢降序排列，比例条使用统一0—100%尺，浅带表示情景范围、深线表示中枢。小比例不能通过单独放大比例尺制造大暴露。区间重叠时不强称排序确定；不同环节的收入纯度可比较业务暴露，但不等于利润含金量相同。

## 4. 五关与C：同敞口，两种不同问题

### 4.1 五关问“该业务走到哪一步”

①故事 → ②订单 → ③收入 → ④主营利润 → ⑤毛利率改善。

必须有对应敞口的依据：有效合同/订单支持②，收入落地支持③，可归因的业务盈利改善支持④，同口径毛利改善支持⑤。可追溯间接证据允许使用，旁边短标“出货线索”等实际性质。

不能用估算数字自行证明③，也不能用公司整体归母、投资收益或其他产品毛利证明④⑤。同一敞口内部子线不同阶段，可以写“部分元件③，光波导②”，不要用最成熟的子线掩盖其他部分。

### 4.2 C问“本次期待的积极变化有多少支持”

| C | 标题 | 完整标准 |
| --- | --- | --- |
| 1 | 缺少有效线索 | 无支持本次积极变化的有效线索；方向、会期本身不加分 |
| 2 | 已有改善线索 | 订单、报价、调研等提供相关线索，但传导关系、可信度或稳定性仍弱 |
| 3 | 变化相对可信 | 同敞口证据更直接，传导更清楚，积极变化正在形成，相对可信 |
| 4 | 变化已经发生 | 直接证据证明本次期待的同敞口积极变化已发生，可信度非常高 |
| 5 | 已发生＋第二曲线 | 满足4分，且未来五年有业务基础和路径支持第二发展曲线想象 |

每家公司按最高完整满足档位评分。C2不要求先证明利润贡献；调研不是天然传闻。C3不要求公司公开分部金额，但须说明业务传导。过去已经发生的增长不自动证明本轮新增变化已发生。

**C是序数评分，禁止映射概率。** 不设置先验30%/40%/50%，不输出胜率、贝叶斯概率或“主观概率”替代品；加上“判断值”也不例外。D/E不另加分；C5的第二曲线是保留的业务加分条件，不宣称与D/E统计独立。

公司整体恶化可以影响业务传导判断，但须有事实说明关联，不能因为另一业务拖累就机械降低眼镜C。整体改善同理不能机械抬高。

## 5. B、下跌主因与总分

### 5.1 B只按固定公式

`R=(前高−参考收盘)/(参考收盘−支撑)`。

| 未四舍五入的R | B |
| --- | --- |
| R＜1 | 1 |
| 1≤R＜2 | 2 |
| 2≤R＜3 | 3 |
| 3≤R＜4 | 4 |
| R≥4 | 5 |

R显示两位小数，判档用原精度。**分子＝有效压力位−参考收盘，分母＝参考收盘−有效支撑位；两侧锚点都必须取日线最近一次被量能测试过的位置，同一取价日、同一复权口径。** 单日最高／最低、未被量能测试过的单根均线、整数关口不得进入公式；只可作文字观察，不进入R。

**锚点依据六字段（写进B栏那一行依据，缺一即视为锚点未成立）**：类别｜价位｜位置日期｜当时量能（成交量或成交额及其与均量对比）｜被测试次数｜测试方式（触及后是否收回）。写不出测试记录时，B标「未取得」、不生成总分；不得先算出R再补一句说明，不默认B2或B5。

**V2.3定稿量化判据**：日线前复权；放量≥1.5×前20个交易日均量；判定窗口最近120个交易日；价格带±1%；触及用最高／最低价，收回与放量用收盘价与成交量；**同一位置至少2次有效测试**（不同交易日、间隔≥5个交易日）；**取价A保守**（支撑取带下沿，压力也取带下沿）；放量收盘跌破支撑带下沿或突破压力带上沿即失效。理由：1.5×过滤噪声；120日匹配90天交易窗口；≥2次降低单次放量误判；A保守避免高估赔率；±1%固定保证可复现。**只有1次测试的位置只作观察位，不进入R；daily_push候选不得用1次测试的锚点。** 如后续证据推翻，按版本升级调整；`anchor_profile` 可切 `legacy_proposal`（1.5×/≥1次/B对称，仅历史复核）或 `strict`（2.0×/≥2次/A）。

**赔率虚高**：有效支撑距现价过近（如不足5%）或分母过小时，在R旁标「赔率虚高·分母X元·支撑距现价Y%」，只作风险提示，不降B档。锚点有效后不得因支撑近、分母小、基本面悲观或“保守原则”临时升降B；对锚点有疑问，核实／重选并重算，不能暗改分档。输入缺失或不满足`前高＞收盘＞支撑＞0`时，B标未取得，总分不生成。

H仅作标签：`H=(收盘/52周最高−1)×100%`，不打分。总分始终`B+C`，不再加入纯度、关卡、节点冲动、H或其他权重。分数不是胜率，也不自动产生仓位。

### 5.2 下跌主因不打分

先检查杀逻辑，再区分杀业绩、杀估值，允许主次混合。一次差业绩不自动等于杀逻辑；确认长期获利机制受损时内部淘汰主动推荐。首屏用短标签，B栏临时试算上方用“下跌主因”一段短说明。

### 5.3 开篇标签白名单与位置

统一放在公司标题、代码等基本信息之后，观点摘要之前。固定顺序：

1. **下跌主因：每篇必有。**
2. **短期下跌主因：仅明确的事件驱动下跌时出现。**
3. **政策依赖度强：仅未来获利前提明显依赖政策时出现。**
4. **技术迭代中：仅满足§2.4时出现。**
5. 原有机会类型、可展望程度标签。

上述六类（最后一项含机会类型、可展望程度两类）是封闭白名单，同类最多一条；后两类沿用已有分类词。禁止另加“核心约束”“风险等级”“政策敏感度”“重点关注”等近义标签。条件不满足直接省略，不留“暂无”。标签应直接回答问题，不允许研究员任意增加同义警示、长篇解释或自造分类。短期事件可以与长期下跌主因同时存在，不相互替代。

### 5.4 下跌主因：必填

格式：`下跌主因：杀业绩为主，伴随估值回落。＋一句具体原因。`

先判断主要性质，再用一句话解释对应事实；不能只写“股价回落”“市场担忧”等无业务含义的描述。

| 分类 | 判断核心 | 所需依据 |
|---|---|---|
| 杀估值 | 盈利或经营路径没有同幅恶化，市场愿意支付的估值倍数下降 | 同期价格、盈利变化、估值与同业变化；不能只凭股价下跌认定 |
| 杀业绩 | 售价、销量、成本等变化压低利润或盈利预期，但核心获利机制仍有成立基础 | 对应经营读数、财报或可追溯调研证据 |
| 杀逻辑 | 核心需求、竞争优势、准入资格或获利方式发生实质、持续性损伤 | 直接对应核心投资前提的证据；不能把一次业绩波动自动当杀逻辑 |

允许“杀业绩为主、伴随估值调整”，但必须明确主次。证据不足须标清判断性质，不得强装确定。已确认杀逻辑的标的不应作为正常推荐交付；指定诊断案例应另行说明，不以高B分抵消。

煤炭示例：**下跌主因：杀业绩为主，伴随估值回落。上半年煤价低位压住售价与毛利。**

### 5.5 短期下跌主因：条件出现

只有近期存在能解释明显加速下跌或相对走弱的具体事件，才加这个标签。普通波动、无明确事件的回调不填，不设“暂无”占位。

格式：`短期下跌主因：事件＋市场担忧的具体影响。`

核验要求：

- 找到事件公开时间，区分签署、公开、实施三个日期。
- 比较事件前后个股与对应敞口板块的表现，使用相同起止日和复权口径；比较区间应覆盖首次公开后的市场反应，不得挑选有利区间。
- 同时检查公司公告、业绩等其他同期催化。事件后跑输是归因线索，不单独证明因果。
- 标签可简短，但依据应在现有证据区可查。尚未完成比较时，不得写成“已核实明显跑输”。

煤炭事件的待核验示例：**短期下跌主因：50号令披露引发政策约束担忧（事件归因，待相对板块走势核验）。**

这是对事件影响的研究判断，尚未独立核验完整相对走势。完成后可用简短确定表述替换括注；不得捏造跑输幅度或沿用错误的事件公开日。

### 5.6 政策依赖度强：暗红标签

判断问题只有一个：**本次期待的积极变化，是否明显依赖未来政策放松、执行宽松、审批通过或约束未实质压缩获利空间？**

如是，就在上述位置显示暗红标签；不因行业“受政策影响”这一泛泛事实给所有公司都贴。不新增政策分数，不自动扣B/C，不新增整块首屏政策面板。

格式：`政策依赖度强：政策或实施节点，消息状态，实施结果状态。`

煤炭案例的政策标签示例（不得无证据复制其状态）：

> 政策依赖度强：12月1日长协保供新规实施，消息已反应，实施结果未知。

“消息已反应”只表示消息已公开且已有市场反应，不等于利空充分定价、全部消化或不会再跌。后续案例若只有公开事实、没有价格反应依据，应写“消息已公布”，不能机械复制本卡文字。

政策适用范围、实施日和来源在原有窗口、证据区展开即可。避免“不是当日必然下跌”“不是可忽略的普通窗口”等防御性套话挤占开篇。

#### 5.6.1 依赖强度三档（2.3正式收录）

强度只用于把「强到什么程度」写成一句可比较的话，不是分数、不改变打不打的结论、不进B/C。

- **强**：政策直接决定本敞口售价、销量或准入（定价机制、长协比例、限产额度、准入资格）。
- **中**：经成本、税费、补贴、环保或安全约束间接影响。
- **弱**：只影响预期与估值。

**强与中可打开篇暗红标签；弱只进06证据，不开标签。** 方向三选一，落在政策节点状态标签：`政策约束 · 不评买入冲动`／`政策支持 · 不评买入冲动`／`政策双向 · 不评买入冲动`；一条文件同时含支持与约束条款时写「政策双向」，不拆两条。

#### 5.6.2 监控成本四字段＋档位（2.3正式收录）

打政策标签即承诺回答监控成本，四字段＋时滞缺一不可：

1. **指标名称**
2. **发布主体与载体**（官网、月报、数据库、交易所披露等）
3. **频率**（日／周／月／季／年／不定期）
4. **获取方式**（免费公开／免费需注册／付费订阅／需线下或商业数据库）
5. **时滞**（发布日至可得的交易日）

档位按最差一项定，不取平均：全部免费公开、频率≤月、时滞≤1交易日→**低**；含需注册或人工整理、或频率≥周、或时滞2—5交易日→**中**；含付费源／商业数据库／线下获取、或频率≥日、或时滞>5交易日、或只有转述无原文→**高**。

另给**周均核查次数**：日=5、周=1、月=0.25、季=0.08；多指标相加后四舍五入到0.5次。只写「需持续跟踪」「密切关注」视为未答第三问。

#### 5.6.3 政策筛查表（2.3正式收录）

起草完成后，把材料中出现的每一条政策（含宏观提法、行业口号、研报转述、公司公告提到的管理办法）逐条过四项准入（A1归属／A2依赖／A3可定位／A4可观测）与七条排除（E1—E7），结论只能落四类之一：

- **打标签**：A1—A4全过、E1—E7未命中；
- **仅作01节点**：有政策内容，但不满足A2或A4；
- **仅进06证据**：E2、E3类历史或待核实事实；
- **排除**：E1、E5、E6、E7类。

筛查表随运行日志/交付说明附出，不上卡面；表内必须覆盖起草材料中出现的全部政策，不许跳条、不许只挑有利的写。缺表或条数少于实际政策条数，视为未完成V2.3。

以上三项在V2.2原为本地增补；V2.3正式收录，交付说明不再标「本地增补」。

## 6. 未来节点：短传导是交付门槛

### 6.1 逐个候选写一次传导路径

内部写：`事件 → 本敞口的可观察变量 → 主标的已有业务承接`，为关键连接标出事实或假设。不把“间接受益”四字当作证据。

节点进入正文，须同时满足：

1. **有关：**事件直接属于主标的、客户或本敞口，能改变当前经营/预期判断。
2. **有桥：**主标的已有对应业务、客户、产品或供应关系依据。行业级节点可以不确认公司份额，但必须说清只检查行业变量，不能声称确认公司订单。
3. **有时点：**90天内有可说明的披露、实施、交付或观察安排，日期性质明确。
4. **有用途：**结果出现后能知道复核哪个主张，而不只是“值得关注”。

允许一个尚待验证的直接传导环节。若还需连续假定两个及以上未获支持的商业环节，**从卡片节点中删除**，不能只降分后继续占位置。路径长度按实际商业假设判断，不靠合并箭头规避。

### 6.2 明确删除的情形

- 只有宏观/技术背景，无法连接本敞口的具体变量。
- 一般性会议，不知有哪些内容与本敞口相关，也无具体检查问题。
- 必须先等应用普及、再等终端需求、再等品牌采购、最后才可能到主标的，关键桥梁没有证据。
- 与另一个节点实质重复，新增日期并不增加判断价值。
- 只有人为设定的日期，没有可说明的经营或政策复核用途。

**AWS例：**云能力发布 → 眼镜应用成熟 → 消费者购买 → 品牌采购 → 歌尔订单，多处商业桥梁未获支持，删除。若以后出现已具名眼镜客户的具体合作、产品或采购安排，应按新事实重新评估，而非永久屏蔽AWS。

**CES例：**AI眼镜新品/量产安排 → 本敞口产品形态与需求预期，且歌尔已有整机业务，允许作为敞口级窗口；不能据会期声称歌尔获得新品订单。双十一读数同样只检查需求，不直接证明公司份额。

### 6.3 日期与内容

90天为报告日及后89个自然日。明确区分实际公告、预约、公司计划、惯例推算、研究员观察窗口；不把季度末/12月31日当自动发生日。海外会期注明当地口径，时刻换算核对夏令时。无确定数据发布日期时写观察范围，不给虚假单日。

每个节点仅保留：**事件名称、回答什么问题、最可能的答案、核心证据、必要的一行复核含义、主标的买入冲动分。** 不重复“用途/预期/该看什么/研究结论”等多套标签。

答案可以是“尚不能判断”，但必须具体说清已知与待确定部分。不能用未知节点凑数量；不要求恰好三个节点。

买入冲动1—10主观评估对主标的的相关性、积极增量、证据和时间；不计入B+C、不映射概率。1—2弱相关/弱线索，3—4增量较弱，5—6触及关键变量但待验证，7—8有支持的高相关增量，9—10需非常突出的明确理由。

### 6.4 节点分级与出货窗口（2.3新增）

`daily_push` 的节点不仅要过§6.1四条件，还要按§2.5分为S／A／B／C四级，并回答“为什么节点后市场愿意给更高价”四问：

1. **谁付钱**：客户、终端、政策执行方或资本市场哪一类参与者。
2. **哪个数字变好**：收入、毛利率、订单、配额、价格、EPS或估值倍数。
3. **为什么节点后市场愿意给更高价**：盈利上修、不确定性消除、供给收缩或稀缺性重估。
4. **什么结果会让节点失效**：写清反证信号，不用“需持续跟踪”代替。

- S／A级节点可作主出货窗口；B级只能辅助；C级软节点只调进度，不作兑现节点。
- `daily_push` 至少要有1个S/A级节点；没有S/A节点、只有C级软节点，不出卡、不推送。
- 首屏或01写「出货窗口：YYYY-MM-DD（S/A节点名称）；谁付钱；哪个数字变好；更高价理由」；这不是目标价，不承诺股价上涨。
- 政策节点仍用状态标签、不评买入冲动；政策节点的复核行写监控成本，不写“值得关注”。

## 7. 检查不等于作废

“最早证伪日”保留字段名，实际指最早可实质检查主张的窗口。不得把到日、没公告或增速未加速直接解释成整卡失效。

| 发生什么 | 应如何处理 |
| --- | --- |
| 没有新读数、披露推迟 | 待确认，更新窗口；不是自动反证 |
| 同口径读数弱于预期 | 复核受影响的需求/业务主张及C，不波及无关结论 |
| 价格锚点失效 | 重审锚点、重算B；不自动判业务逻辑错误 |
| 关键客户/产品/经营机制出现实质反证 | 重评相应敞口主张与关卡，必要时撤销研究结论 |
| 长期获利机制被破坏 | 下跌主因重审，确认杀逻辑后停止主动推荐 |

领航员提供证据与重审对象，操盘手决定卖出等执行。单季扣非转负、连续两季毛利下降等数值不能未经验收自动定义为杀逻辑。

## 8. 其余研究模块

- **D可展望（三年）/E可想象（长期）：**未建立、初步建立、有支撑、较完整四级；各写业务驱动、企业承接与关键约束，不计总分。首屏成长标签跟随D实际等级。
- **下行参照：**哪些坏事→整体利润假设→行业平均估值→价格。行业PE默认正盈利可比公司TTM等权平均，公开样本、日期、亏损/极端值处理；压力系数标判断，不用本股PE冒充行业锚。
- 眼镜收入不能无利润率、费用与其他业务桥梁直接变成归母。不能精确拆时，直接给公司整体情景并标假设，避免伪精确。
- 最悲观且可合理估价的区间若包含收盘价（含边界），低饱和高亮“悲观区间覆盖现价”；低于整个区间另标。不能估值的杀逻辑情景不硬编价格底。
- **证据底稿：**只留改变判断的已发生事实，按时序排列。推断与传闻补充层默认关闭，评分和必要答案仍在使用处可见。
- 调研、客户反馈、媒体转述均允许；标清来源与限制。检索摘要不能冒充已阅读全文，同一消息转载不能称多个独立证据。

### 8.1 技术模块必须先下判断，再给证据

仅触发§2.4时使用。顺序固定：一行触发原因 → 当前观点 → 路线表 → 重点公司方向性比较 → D/E。长情景与细项参数折叠，不隐藏核心反证。

1. **当前观点：**站在报告日，明确哪个机会仍成立、哪个约束已影响交易价值、谁在何种情景占优。不能只罗列“有风险”“需关注”；技术承接优势、当期利润证据、价格吸引力必须分清。
2. **路线表：**按应用/地区比较当前路线、替代方案、政策/认证/成本/专利约束、切换时间与观察变量。规划、研发、中试、量产、认证、收入、利润分别标明；新一代不自动等于全面替代。
3. **公司观点：**至少比较主标的与直接对手，使用“观点→证据→改变观点的信号”。优先复用同敞口公司；替代路线不同受益者可作条件参照，不能混入原敞口纯度冒充同业务。
4. **情景覆盖：**现路线先兑现、替代加速、二者均未兑现；说明利润归属和复核信号。不能把三个情景写成概率表或自动交易预案。

标题必须有判断。“当前集中度与下一代兑现”“覆盖更广，仍须核对”“更值得比较”只描述研究对象/动作，不能代替结论。合格示例：“三美更集中押注本轮价差，下一代溢价依据不足”；“巨化跨代承接依据更强，路线切换时优先研究”。这些是案例判断，不得照搬到其他公司。

观点有方向不等于强装确定；证据不足时准确限定“本卡已核实依据”的比较范围，明确缺的关键证据，不用保留句覆盖整段观点。禁止为观点性制造份额、专利阻断或客户认证；查到产品名录不能直接称量产盈利，查到专利不能直接称本公司被阻断。

跨代优先研究不等于当前价格最值得买；技术优势未提供新增短期盈利证据时，不自动提高C。技术模块不计分，不新增仓位、止损和执行指令。

## 9. 可读性规范：有明确的删减顺序

### 9.1 信息放在哪里

| 位置 | 保留什么 | 不放什么 |
| --- | --- | --- |
| 首屏 | 产业主升判断、主张与矛盾、重要下滑归因、条件标签、最近节点、出货窗口、总分与四个速览 | 多段结论、长算式、研究过程、版本对话 |
| 节点 | 事件、问题、答案、最核心证据、冲动 | 多跳背景、重复用途、无依据大概率 |
| 同敞口表 | 纯度中枢/范围、60/120/250交易日绝对/相对跌幅读数、业务阶段依据、B/C/R | 大分部替身、整段模型、每股利多利空清单 |
| 折叠区 | 纯度参数、公司整体背景、评分依据、来源 | 用折叠掩盖与结论相反的关键信息 |
| 内部底稿 | 取数快照、全模型、跌幅榜读数、候选淘汰与修改记录 | 整体搬到正文 |

`daily_push` 的「跌幅读数」「出货窗口」是必填内容，不是新标签、不计分；使用现有`.note`／`.compact`／`.metric`／`.review-note`样式，不新增CSS、不改六节结构。

### 9.2 编辑时依次删

1. 重复结论、读者已看见的数字复述。
2. “原报告/原卡/与上一版相比”等依赖旧版本的过程文字。
3. “需要时展开/只供参考/保留原主标的”等无新增信息的说明。
4. 不改变主张、评分、节点、阶段或风险判断的背景。
5. 将长参数和计算移入一个统一折叠区。

压缩不能删掉估计标识、日期性质、来源限制和关键反证。正文判断通常1—2句；首屏产业摘要通常约80—140字；有重要经营回落时允许另加1—2句原因，不能为字数删掉关键归因；超出时先删重复，不强行缩字号。每个段落问：“去掉后，操盘手会失去什么具体判断信息？”答不出就删除或移入底稿。

## 11. 实现与工作流

1. 读取本规范、母版与执行细则；锁定报告基准日、取价日、模式（`named_research`／`daily_push`）、敞口约定。
2. `daily_push`先执行§2.5：60／120／250交易日跌幅榜→区间涨跌幅＋最大回撤＋相对基准跌幅→下跌原因→90天节点地图S/A/B/C→只保留“跌幅榜＋S/A节点”共振候选。`named_research`可直接研究点名标的，但仍按本规范。
3. 主动推荐过准入三条：未确认杀逻辑、B≥3、C≥3、B＋C≥7；**MA5／MA10只作行情事实，不作门槛**。用公司披露、客户材料、协会、调研等搜集证据，补查延期、取消及已兑现信息。
4. 完成§2.1—2.5：产业观点、下滑归因、终端与利润映射、技术重要性、daily_push筛选；随后所有公司统一估计纯度，检查参数与合并范围；确定本敞口关卡与同一主张的C。
5. 对候选节点逐项执行第6节：多跳且缺桥的直接删除；保留的日期、问题、答案须能独立理解；daily_push节点按§2.5分级，至少1个S/A。
6. 用固定函数算B、总分、排序和显示；B锚点按§5.1六字段与量能测试规则；判断D/E及下行情景。源数据只维护一份。
7. 排序：`daily_push`按节点质量＞跌幅可解释/可剥离＞B/C＞纯度；`named_research`按纯度×兑现进度，并说明与准入的关系。
8. 按第9节压缩正文；按§5.3—5.7生成开篇标签，复制母版生成独立HTML；写「跌幅读数」「出货窗口」；核对本版不依赖历史文件里的数字或规则。
9. 打印副本按§10.1：A4、≤6页、保留图形/配色、删除规则与来源、展开折叠；PDF不替代HTML。
10. 执行下面全部内容检查，再验数字、交互与版式。失败先修复，不以“待核验”标签掩盖未完成的核心比较。

内部数据至少包含：产业主升命题与成立条件、下滑原因及来源性质、终端份额口径与供应映射、利润环节比较、技术重要性触发与否及理由、历版共识核对、敞口约定、每家公司纯度三情景与参数来源、关卡证据、C主张与依据/反证、价格原始输入、60/120/250交易日跌幅与最大回撤、节点分级与出货窗口、B锚点六字段、节点传导路径及取舍理由、行业PE样本和利润假设；MA仅作行情事实（如有展示）。

### 12.5 2.2新增：产业、归因、终端与观点检查

- [ ] 开篇有具体敞口主升判断、驱动与成立条件；证据不足明确说明，不只有公司数字。
- [ ] 重要收入、利润或经营下滑在概述解释，区分同比/环比、范围和来源性质；没有把增速放缓写成下降。
- [ ] 公司毛利不冒领窄敞口毛利；税项不解释毛利、销量不自动解释吨毛利；C与同一积极变化相符。
- [ ] 终端前5—10家按可得资料检查，份额期间/地区/指标一致，匿名身份为推断，具名供应独立取证；不足不凑排名。
- [ ] 利润环节已经检索；不能比较时明示，未伪称最高毛利环节或把不同口径硬排。
- [ ] 技术重要性每份都检查并有内部记录；只在触发时贴标签、展开04，未替代原D/E。
- [ ] 04有明确方向、相对取舍、证据及改变结论信号，不以研究动作代替观点。
- [ ] 技术场景、地域、时间、配额当量/实物吨、研发/投产/盈利区分；长期替代不冒充90天节点。
- [ ] 2.1标签约束、政策提示和下跌主因，2.0同敞口/短传导/独立性，及基础B+C、试算、证据开关全部保留并检查；MA不再作为门槛。

### 12.6 2.3新增：跌幅榜、节点、锚点与打印检查

- [ ] `daily_push`候选来自60／120／250**交易日**跌幅榜；标明挂在哪个窗口、哪个跌幅更大；区间涨跌幅＋最大回撤＋相对基准跌幅（行业或沪深300）都写了；窗口不足写「不存在」。
- [ ] 每只候选写了下跌原因（杀估值／杀业绩／杀逻辑、主次、证据、可解释性、可剥离性、最乐观那天能否定义）；确认杀逻辑未进daily_push。
- [ ] 90天节点按S／A／B／C分级；daily_push至少1个S/A；B级只辅助；C级软节点没有当兑现节点。
- [ ] 节点过§6.1四条件，并回答出货四问（谁付钱／哪个数字变好／为什么更高价／什么信号失效）。
- [ ] 卡片首屏或01有「出货窗口」；03第一列或06有「跌幅读数」；没有S/A节点或不在跌幅榜时没有出daily_push卡。
- [ ] daily_push排序按节点质量＞跌幅可解释/可剥离＞B/C＞纯度；没有为了凑共振下调B/C。
- [ ] B锚点两侧都是日线最近一次被量能测试过的位置；B栏六字段齐全；写不出测试记录→B「未取得」、不生成总分；没有先算R再补说明。
- [ ] 赔率虚高只标注、不降档；B档没有因支撑近/分母小/基本面悲观主观改动。
- [ ] 全文（含隐藏层、meta、JSON）无MA准入判定、无“均线不过即观察”、无概率映射。
- [ ] 打印副本按§10.1：A4、≤6页、保留图形/配色、删除规则与来源、展开折叠、未改原HTML；PDF不替代HTML。
- [ ] 未读取任何外部金融日历仓库；交易日按交易所公告核对。

### 12.7 2.3新增：政策三问与筛查表

- [ ] 政策标签只走§5.3白名单，位置在公司标题与代码之后、观点摘要之前；条件不成立整块删除，不留空、不写「暂无」。
- [ ] 政策身份五项齐全：文件名、发文机关、文号（无文号注明）、最早公开信号日、条款位置。
- [ ] 依赖强度写清强／中／弱；只有强与中可开标签，弱只进06；方向写清政策约束／政策支持／政策双向。
- [ ] 监控成本四字段（指标｜发布主体与载体｜频率｜获取方式）＋时滞＋档位＋周均核查次数齐全；只写「持续跟踪」视为未答。
- [ ] 政策筛查表覆盖材料中全部政策，结论落「打标签／仅01节点／仅06证据／排除」四类并带A/E理由码；随运行日志/交付说明附出，不上卡面。
- [ ] 政策不新增分数、不自动扣B/C；政策事实进入C的支持/反证，但不因「政策已实施」直接给C4。
- [ ] 未把「消息已反应」写成「已充分定价」；只有公开事实时写「消息已公布」。

## 14. 交给模型的简短入口

> 使用本规范与Version2.2三美HTML母版，为指定个股或敞口制作报告。`daily_push`先执行§2.5：60／120／250交易日跌幅榜→区间涨跌幅＋最大回撤＋相对基准跌幅→下跌原因→90天S/A/B/C节点→只保留“跌幅榜＋S/A节点”共振候选；无S/A节点、只有C级软节点、或不在跌幅榜的候选不出daily_push卡。`named_research`可直接研究点名标的，但仍按本规范。先执行§2：产业主升判断、经营下滑归因、终端反推与利润去向、技术重要性；锁定敞口比较约定；纯度允许间接证据估计，但全表同口径，关卡和C只评价该敞口。B锚点两侧都取日线最近一次被量能测试过的位置，写类别｜价位｜日期｜量能｜测试次数｜测试方式；写不出测试记录→B「未取得」、不生成总分；MA5／MA10只作行情事实，不作准入门槛；准入三条＝未确认杀逻辑、B≥3、C≥3、B＋C≥7。逐节点检查传导，删除多跳缺桥；写清「跌幅读数」与「出货窗口」。开篇标签严格执行§5.3—5.7白名单，不自行扩展。独立交付一个HTML；打印副本按§10.1，A4、≤6页、保留图形/配色，PDF不替代HTML。交付前逐项完成§12（含§12.6）自查；不读取外部金融日历仓库；新研究重新取证，不能照搬样稿数值。

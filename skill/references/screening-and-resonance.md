# 跌幅榜 × 90 天现象级节点：筛选与共振标准

本文件是 2026-11-10 用户确认的 `daily_push` 筛选标准。它不改变 B／C 公式，也不新增分数；它决定**先看谁、为什么看、什么时候可以出卡**。

用户原话：

> 由于我对于赔率有要求，所以你一定不要忘记从最近 60 天、最近 120 天和最近 250 天的跌幅榜中选股票，这样才能去找到下跌原因。与此同时，为了提高业务贴合度，最重要的其实是在未来有一个很明确的兑现节点，所以在筛选的时候，你也可以从事件驱动的视角出发，未来 90 天是否存在某一个特别现象级的节点，能让我们顺利以更高的价格出货，这是最重要的。合适的时机。当然！如果跌幅榜和未来明确预期的节点共振了！这就是一个非常好的交易机会！

## 1. 筛选顺序（不可颠倒）

```
① 60/120/250 交易日跌幅榜
→ ② 区间涨跌幅＋最大回撤，去重、剔不符合条件的
→ ③ 定义敞口，查清下跌原因（杀估值／杀业绩／杀逻辑）
→ ④ 建 90 天节点地图，给节点质量分级
→ ⑤ 只保留「跌幅榜 + S/A 级节点」共振的候选
→ ⑥ B/C 准入、纯度、同敞口比较
→ ⑦ 出卡与推送
```

**没有跌幅榜来源的候选，不得进入 daily_push。**
**没有 S/A 级 90 天节点的候选，不得进入 daily_push。**
**跌幅与节点不共振的候选，最多进内部观察，不出卡、不推送。**

## 2. 跌幅榜口径（用户 2026-11-10 确认）

| 项目 | 口径 |
| --- | --- |
| 窗口 | 60／120／250 **交易日**（约 3／6／12 个月） |
| 区间涨跌幅 | 窗口首日收盘 → 窗口末日收盘，前复权；正数为涨、负数为跌 |
| 最大回撤 | 窗口内从阶段高点到之后最低点的最大跌幅；与区间涨跌幅分开列，不混算 |
| 相对跌幅 | 个股区间涨跌幅−行业指数同期涨跌幅；行业指数优先（申万/同花顺），不可用时用沪深300或中证全指并注明；同一窗口、同一复权口径 |
| 排序 | 每个窗口单独排序；不得把不同窗口混成一个榜单 |
| 去重 | 同一股票可同时在多个窗口出现；必须注明它挂在哪个窗口、哪个跌幅更大 |
| 窗口不足 | 上市不满窗口、长期停牌、数据缺失：写「不存在」，不外推、不补数 |
| 默认剔除 | ST／*ST、退市风险、上市不足 60 个交易日、长期停牌、日均成交额过低；named_research 可例外，但须说明 |
| 数据 | 前复权日线；同源同截止日；截止日取报告日前最近一个已收盘交易日 |

**读法**：

- 相对跌幅用于区分“行业普跌”与“个股错杀”：相对跌幅接近0＝行业普跌，明显为负＝个股跑输；不单独作准入门槛，也不替代下跌原因分析。
- 60 交易日跌幅榜：找短期错杀、一次性冲击、情绪出清。
- 120 交易日跌幅榜：找中期估值收缩、景气预期下修。
- 250 交易日跌幅榜：找逻辑是否真被杀过、悲观是否充分展开。
- 区间涨跌幅大但最大回撤小：可能是缓慢阴跌，未必充分展开。
- 区间涨跌幅小但最大回撤大：可能中途深跌后收回，须看收回的证据。

## 3. 下跌原因：必须查，且要能回答「能不能剥离」

每个跌幅榜候选都要写：

```
下跌读数（窗口、区间涨跌幅、最大回撤）
→ 下跌起点与触发事件
→ 原因分类：杀估值／杀业绩／杀逻辑（允许主次混合）
→ 证据：价格、盈利、估值、同业、公告、调研
→ 可解释性：能解释／部分解释／尚未查明
→ 可剥离性：可剥离／部分可剥离／不可剥离
→ 最乐观那天能否定义：能／不能；若能，是哪一天、什么条件
```

- **杀估值**：盈利路径没有同幅恶化，估值倍数下降。不是剔除理由；要判断悲观是否充分展开。
- **杀业绩**：售价、销量、成本压低利润或盈利预期，但核心获利机制仍有成立基础。要说明恢复机制。
- **杀逻辑**：核心需求、竞争优势、准入资格或获利方式发生实质、持续损伤。**确认杀逻辑的标的，daily_push 直接淘汰。**
- 没有跌幅（区间涨跌幅为正）的标的：写「未杀」，不得硬套三分法；只能作为节点驱动候选，且必须另外说明为什么现在看。
- 找不到原因：写「尚未查明」及影响；不得编故事。若缺口使关键 C 依据不成立，淘汰。

## 4. 90 天节点：质量分级

「现象级节点」不是所有会议和展会。按下面四级判定；**daily_push 至少要有 S 或 A 级节点**。

| 级别 | 定义 | 例子 | daily_push |
| --- | --- | --- | --- |
| **S** | 硬节点＋公司专属＋日期确定＋直接改变利润/价格/配额 | 业绩预告/快报、定期报告、政策实施日直接改变本敞口售价或配额、重大订单交付/验收、解禁/股东会中能改变供需的议案 | 可作主出货窗口 |
| **A** | 硬节点＋日期确定＋间接影响；或高确定性软节点＋公司专属订单/价格/客户事件＋日期可核 | 行业月度数据、政策执行细则、涨价函、公司订单/中标、客户认证、产品量产、展会中公司明确参展并有新品 | 可作主出货窗口，但需写清桥梁 |
| **B** | 行业级数据/会议，有固定日历，但无公司专属确认 | 海关月度出口、行业协会月度数据、一般性行业会议 | 只能作辅助节点，不能单独作为出货窗口 |
| **C** | 软节点，有日期但无披露义务，只调整「进度」 | 一般展会、双十一、媒体预期、无具名客户的“有望” | 不作兑现节点；不得作为 daily_push 理由 |

**硬节点**：有法定披露义务、日期锁死（定期报告、业绩预告/快报、股东大会、解禁、政策施行日）。
**软节点**：展会、涨价函、订单、政策信息窗口；日期公开但不产生披露义务，只能调整「进度」这一个判断，不能当兑现节点用。

### 4.1 节点必须回答「为什么能以更高价出货」

每个 S/A 节点必须写清：

1. **谁付钱**：客户、终端、政策执行方、资本市场哪一类参与者。
2. **哪个数字变好**：收入、毛利率、订单、配额、价格、EPS、估值倍数。
3. **为什么节点后市场愿意给更高价**：是盈利上修、不确定性消除、供给收缩、还是稀缺性重估。
4. **改变观点的信号**：什么结果会让这个节点失效。

答不出这四问的节点，不是「现象级」，不能作为出货窗口。

## 5. 共振分级

| 级别 | 条件 | 处理 |
| --- | --- | --- |
| **强共振** | 至少一个 60/120/250 交易日跌幅榜 + S 级节点 + B≥4 + C≥4 + 未确认杀逻辑 | daily_push 优先；可出卡 |
| **中共振** | 至少一个跌幅榜 + A 级节点 + B≥3 + C≥3 + 未确认杀逻辑 | daily_push 可出卡 |
| **弱共振** | 只有跌幅榜没有 S/A 节点，或只有 S/A 节点不在跌幅榜 | 内部观察，不出卡、不推送；named_research 可呈现但标明「非 daily_push」 |
| **不成立** | 确认杀逻辑，或 B/C 不过线，或节点四条件不过 | 淘汰；不进推送 |

**排序**：节点质量 ＞ 跌幅可解释/可剥离 ＞ B/C ＞ 纯度。
两个候选同级时，优先「节点更近、日期更硬、桥梁更短」的那个。

## 6. 卡片必须多写的两行

### 6.1 跌幅读数

在 03 同敞口表的第一列或 06 证据里，写：

`60/120/250 交易日：绝对 −x%／−y%／−z%；相对行业或沪深300 −x%／−y%／−z%；区间最大回撤 −w%；来源：前复权日线，截止 YYYY-MM-DD。`

- 三个窗口都写；不足写「不存在」；相对基准写清所用指数与口径。
- 正数写「+x%」，不要写成跌幅。
- 不得只写「跌了很多」「跌幅较大」。

### 6.2 出货窗口

在首屏或 01 窗口写：

`出货窗口：YYYY-MM-DD（S/A 级节点名称）；谁付钱：…；哪个数字变好：…；节点后更高价的理由：…。`

- 没有 S/A 节点：daily_push 不出卡。
- 只有 B/C 级节点：写「本轮无可作出货窗口的节点」，不出卡。
- 出货窗口不是目标价，不承诺股价上涨。

## 7. 无合格时的推送文案

| 情形 | 文案 |
| --- | --- |
| 跌幅榜有候选，但无 S/A 节点 | `本轮全市场未检索到「跌幅榜＋90天现象级节点」共振的合格敞口。`＋最多 3 个被否决候选（写明「无S/A节点」） |
| 有 S/A 节点，但不在跌幅榜或 B/C 不过线 | `本轮有节点候选，但没有跌幅榜与赔率同时成立的敞口。`＋最多 3 个被否决候选 |
| 跌幅榜与节点都有，但确认杀逻辑 | `本轮跌幅榜候选多数已确认杀逻辑，未找到可推荐的共振敞口。` |
| 数据源不可用 | `本轮全市场未检索到符合准入的产业敞口（数据源不可用，未取得）。` |

## 8. 红线

- 🔴 不得跳过 60/120/250 交易日跌幅榜直接选股。
- 🔴 不得只看涨幅榜、热门板块或概念名单。
- 🔴 不得把 B/C 级软节点写成「现象级」或「兑现节点」。
- 🔴 不得用「市场关注度高」「板块情绪」当更高价的理由。
- 🔴 不得为了凑共振下调 B/C，或把未过线标的包装成推荐。
- 🔴 确认杀逻辑的标的，不得进 daily_push。
- 🔴 跌幅窗口、最大回撤、节点质量、出货窗口四项缺一，不得出 daily_push 卡。

## 9. 与既有规则的关系

- B/C 公式、纯度、同敞口、标签、政策、证据规则不变。
- 本文件只增加 **候选来源** 与 **节点质量/共振** 的筛选门槛。
- 硬节点/软节点的既有定义来自 `research-perspective.md` 与 `scoring-and-timeline.md`；本文件不改变它们的口径，只给分级。
- 与 `daily-push.md` 的候选池、`preflight-checklist.md` 的 I/K 组、`workbuddy-setup.md` 的定时任务提示词配套使用。

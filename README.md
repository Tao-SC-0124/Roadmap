## 维护约定

1. 根目录只放仓库说明和必要配置，业务文件按主题归档。
2. 信息卡每次升级新建 `信息卡/VersionX.Y/`，放执行规范、HTML母版与该版研发记录；旧版保留，不覆盖历史版本。
3. 日历按年份归档，文件名保留生成日期；不同日期的文件不相互覆盖。
4. 当前版本更新时同步维护本页入口，规范与母版放在同目录，使用相对链接。
5. `.制作/`用于本地脚本、截图等临时材料，不提交；系统杂项由`.gitignore`忽略。

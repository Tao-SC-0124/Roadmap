# 产业信息卡 Version2.0：研究员执行规范

业务版本：2.0。制定日期：2026-11-02。

本规范独立生效。视觉母版为同目录的 [AI眼镜-歌尔股份-产业信息卡-Version2.0.html](./AI眼镜-歌尔股份-产业信息卡-Version2.0.html)。制作新报告时复制母版结构和样式，重新研究并替换全部数据，不复制案例结论。本文件不要求另读V1.0。

## 1. 任务与边界

投资原则：**持有具备安全边际的高成长股，并通过波段操作平滑收益。** 允许明确区分的事件型机会。

领航员负责敞口定义、证据搜集、纯度估计、下跌归因、未来节点、评分及比较；操盘手负责技术核验、仓位、交易和退出。报告是一份可快速扫读的路书，不是资料堆积。

- 每个敞口仅交付一个独立HTML，包含主标的、同敞口公司、评分、节点、成长、下行参照与来源。
- 输入为个股：识别敞口，保留指定主标的。输入为敞口：先找直接受益公司，再按资格选择主标的；无合格公司可以不推荐。
- 主动推荐必须通过：最近完成交易日**日线简单MA5＞MA10**、未确认杀逻辑、B≥3、C≥3、B+C≥7。MA同源、同复权、同截止日，用有效交易日收盘价计算。
- 指定个股可以研究不合格样本，但不能宣称已正式入池。评分达线不代替其他门槛。
- 用户明确修改优先，其次本规范，其次母版视觉；历史案例和旧指令不能覆盖本规范。
- 独立HTML使用内联CSS/原生JS；折叠、试算、证据开关离线工作。不要加外部脚本、自动外发或追踪。

## 2. 先锁定一份“敞口比较约定”

打分和找公司之前，在内部数据中确定以下字段，并在同敞口表前用两句以内概括：

| 字段 | 必须确定的内容 |
| --- | --- |
| 敞口 | 具体产品、业务、环节；列出必须排除的邻近业务 |
| 本次积极变化 | 同一个可观察命题，例如“AI眼镜新增业务继续向公司收入传导” |
| 期间 | 已实现期间、全年预测或年度运行率情景，必须明确是哪一种 |
| 收入口径 | 归属于上市公司合并范围的该敞口收入；分母为公司同期间总营收 |
| 证据口径 | 各公司允许使用同等的直接/间接证据，不能一家公司严、一家公司松 |

**纯度、五关和C必须使用这同一个敞口。** 公司整体数据只能放背景或解释拖累，不得借其他业务的增长给本敞口升级。B仍取公司股价，这是股权投资工具的价格维度，不与业务纯度混算。

例：AI眼镜卡中，歌尔的智能硬件大分部与立讯的消费电子大分部不可直接比较；水晶手机光学的毛利率改善不能算眼镜第五关；立讯汽车和数据中心增长不能算眼镜C4。

## 3. 纯度：必须可比，允许有依据的推测

### 3.1 计算与证据

`纯度 = 本公司该敞口可归属收入 ÷ 本公司总营业收入`。

优先使用单列披露；未单列时，用客户、机型、供应关系、出货、单机价值、份额、产线或可追溯调研搭建估计。**不因缺直接披露就停止比较，也不能用相邻大板块代替窄敞口。**

估计至少保留：分子计算、分母、期间、币种/单位、关键参数、各参数属于事实还是假设、来源及日期。一条可追溯间接证据可以支持假设，不设必须几条公告的机械门槛。

常用自上而下模型：`Σ细分出货量 × 公司份额 × 本公司该环节单机收入`。也可以自下而上汇总客户项目；采用其他模型时仍须满足相同边界。

### 3.2 不得省略的约束

- 全表统一产品范围与期间。实际收入、预测收入、潜在产能不能混排成“已实现收入”。
- 全年分子与前三季×4/3分母搭配时，明确称“全年收入情景/年化运行率代理”，不能称真实全年纯度。检查季节性偏差；有可靠全年分母预测则同口径使用。
- 机构A总量与机构B结构比例的定义、期间不一致，不得冒称联合事实。可在情景中显式假设，并说明限制。
- 整机收入已含内部部件时，不再加同公司内部自供收入；外供部分只计合并范围对外交易。
- 联营企业收入不直接并入上市公司营收分子；投资收益与营业收入分开。
- 同一细分的份额相加、客户覆盖范围、单机价值与整机价格不得逻辑冲突。新品尚未量产，不能写成当期已实现收入。
- 不把模型计算结果反过来当作订单、收入或C4的独立证据。
- 不为满足“必须估计”编造一个无任何业务锚点的比例；先补查、建立有业务边界的宽情景。确实无法形成有意义量级时，报告该参照未完成，不伪称已完成可比排名。

### 3.3 范围、排序与展示

对未披露纯度，给低/中/高三种有明确参数的情景，实际重算范围。不是在一个数字上随意加“±5个百分点”，也不叫统计置信区间。

表面只显示：**公司、代码、中枢百分比、情景范围、业务角色**。中枢约1位小数即可。计算明细统一收进表后的“纯度估算依据”。

按中枢降序排列，比例条使用统一0—100%尺，浅带表示情景范围、深线表示中枢。小比例不能通过单独放大比例尺制造大暴露。区间重叠时不强称排序确定；不同环节的收入纯度可比较业务暴露，但不等于利润含金量相同。

## 4. 五关与C：同敞口，两种不同问题

### 4.1 五关问“该业务走到哪一步”

①故事 → ②订单 → ③收入 → ④主营利润 → ⑤毛利率改善。

必须有对应敞口的依据：有效合同/订单支持②，收入落地支持③，可归因的业务盈利改善支持④，同口径毛利改善支持⑤。可追溯间接证据允许使用，旁边短标“出货线索”等实际性质。

不能用估算数字自行证明③，也不能用公司整体归母、投资收益或其他产品毛利证明④⑤。同一敞口内部子线不同阶段，可以写“部分元件③，光波导②”，不要用最成熟的子线掩盖其他部分。

### 4.2 C问“本次期待的积极变化有多少支持”

| C | 标题 | 完整标准 |
| --- | --- | --- |
| 1 | 缺少有效线索 | 无支持本次积极变化的有效线索；方向、会期本身不加分 |
| 2 | 已有改善线索 | 订单、报价、调研等提供相关线索，但传导关系、可信度或稳定性仍弱 |
| 3 | 变化相对可信 | 同敞口证据更直接，传导更清楚，积极变化正在形成，相对可信 |
| 4 | 变化已经发生 | 直接证据证明本次期待的同敞口积极变化已发生，可信度非常高 |
| 5 | 已发生＋第二曲线 | 满足4分，且未来五年有业务基础和路径支持第二发展曲线想象 |

每家公司按最高完整满足档位评分。C2不要求先证明利润贡献；调研不是天然传闻。C3不要求公司公开分部金额，但须说明业务传导。过去已经发生的增长不自动证明本轮新增变化已发生。

**C是序数评分，禁止映射概率。** 不设置先验30%/40%/50%，不输出胜率、贝叶斯概率或“主观概率”替代品；加上“判断值”也不例外。D/E不另加分；C5的第二曲线是保留的业务加分条件，不宣称与D/E统计独立。

公司整体恶化可以影响业务传导判断，但须有事实说明关联，不能因为另一业务拖累就机械降低眼镜C。整体改善同理不能机械抬高。

## 5. B、下跌主因与总分

### 5.1 B只按固定公式

`R=(前高−参考收盘)/(参考收盘−支撑)`。

| 未四舍五入的R | B |
| --- | --- |
| R＜1 | 1 |
| 1≤R＜2 | 2 |
| 2≤R＜3 | 3 |
| 3≤R＜4 | 4 |
| R≥4 | 5 |

R显示两位小数，判档用原精度。前高、支撑由领航员选择，必须有真实数据依据，操盘手核验技术面。

**锚点有效后，不得因支撑近、分母小、基本面悲观或“保守原则”临时升降B。** 对锚点有疑问，核实/重选并重算，不能暗改分档。输入缺失或不满足`前高＞收盘＞支撑＞0`时，B标未取得，总分不生成，不能默认B2或B5。

H仅作标签：`H=(收盘/52周最高−1)×100%`，不打分。总分始终`B+C`，不再加入纯度、关卡、节点冲动、H或其他权重。分数不是胜率，也不自动产生仓位。

### 5.2 下跌主因不打分

先检查杀逻辑，再区分杀业绩、杀估值，允许主次混合。一次差业绩不自动等于杀逻辑；确认长期获利机制受损时内部淘汰主动推荐。首屏用短标签，B栏临时试算上方用“下跌主因”一段短说明。

## 6. 未来节点：短传导是交付门槛

### 6.1 逐个候选写一次传导路径

内部写：`事件 → 本敞口的可观察变量 → 主标的已有业务承接`，为关键连接标出事实或假设。不把“间接受益”四字当作证据。

节点进入正文，须同时满足：

1. **有关：**事件直接属于主标的、客户或本敞口，能改变当前经营/预期判断。
2. **有桥：**主标的已有对应业务、客户、产品或供应关系依据。行业级节点可以不确认公司份额，但必须说清只检查行业变量，不能声称确认公司订单。
3. **有时点：**90天内有可说明的披露、实施、交付或观察安排，日期性质明确。
4. **有用途：**结果出现后能知道复核哪个主张，而不只是“值得关注”。

允许一个尚待验证的直接传导环节。若还需连续假定两个及以上未获支持的商业环节，**从卡片节点中删除**，不能只降分后继续占位置。路径长度按实际商业假设判断，不靠合并箭头规避。

### 6.2 明确删除的情形

- 只有宏观/技术背景，无法连接本敞口的具体变量。
- 一般性会议，不知有哪些内容与本敞口相关，也无具体检查问题。
- 必须先等应用普及、再等终端需求、再等品牌采购、最后才可能到主标的，关键桥梁没有证据。
- 与另一个节点实质重复，新增日期并不增加判断价值。
- 只有人为设定的日期，没有可说明的经营或政策复核用途。

**AWS例：**云能力发布 → 眼镜应用成熟 → 消费者购买 → 品牌采购 → 歌尔订单，多处商业桥梁未获支持，删除。若以后出现已具名眼镜客户的具体合作、产品或采购安排，应按新事实重新评估，而非永久屏蔽AWS。

**CES例：**AI眼镜新品/量产安排 → 本敞口产品形态与需求预期，且歌尔已有整机业务，允许作为敞口级窗口；不能据会期声称歌尔获得新品订单。双十一读数同样只检查需求，不直接证明公司份额。

### 6.3 日期与内容

90天为报告日及后89个自然日。明确区分实际公告、预约、公司计划、惯例推算、研究员观察窗口；不把季度末/12月31日当自动发生日。海外会期注明当地口径，时刻换算核对夏令时。无确定数据发布日期时写观察范围，不给虚假单日。

每个节点仅保留：**事件名称、回答什么问题、最可能的答案、核心证据、必要的一行复核含义、主标的买入冲动分。** 不重复“用途/预期/该看什么/研究结论”等多套标签。

答案可以是“尚不能判断”，但必须具体说清已知与待确定部分。不能用未知节点凑数量；不要求恰好三个节点。

买入冲动1—10主观评估对主标的的相关性、积极增量、证据和时间；不计入B+C、不映射概率。1—2弱相关/弱线索，3—4增量较弱，5—6触及关键变量但待验证，7—8有支持的高相关增量，9—10需非常突出的明确理由。

## 7. 检查不等于作废

“最早证伪日”保留字段名，实际指最早可实质检查主张的窗口。不得把到日、没公告或增速未加速直接解释成整卡失效。

| 发生什么 | 应如何处理 |
| --- | --- |
| 没有新读数、披露推迟 | 待确认，更新窗口；不是自动反证 |
| 同口径读数弱于预期 | 复核受影响的需求/业务主张及C，不波及无关结论 |
| 价格锚点失效 | 重审锚点、重算B；不自动判业务逻辑错误 |
| 关键客户/产品/经营机制出现实质反证 | 重评相应敞口主张与关卡，必要时撤销研究结论 |
| 长期获利机制被破坏 | 下跌主因重审，确认杀逻辑后停止主动推荐 |

领航员提供证据与重审对象，操盘手决定卖出等执行。单季扣非转负、连续两季毛利下降等数值不能未经验收自动定义为杀逻辑。

## 8. 其余研究模块

- **D可展望（三年）/E可想象（长期）：**未建立、初步建立、有支撑、较完整四级；各写业务驱动、企业承接与关键约束，不计总分。首屏成长标签跟随D实际等级。
- **下行参照：**哪些坏事→整体利润假设→行业平均估值→价格。行业PE默认正盈利可比公司TTM等权平均，公开样本、日期、亏损/极端值处理；压力系数标判断，不用本股PE冒充行业锚。
- 眼镜收入不能无利润率、费用与其他业务桥梁直接变成归母。不能精确拆时，直接给公司整体情景并标假设，避免伪精确。
- 最悲观且可合理估价的区间若包含收盘价（含边界），低饱和高亮“悲观区间覆盖现价”；低于整个区间另标。不能估值的杀逻辑情景不硬编价格底。
- **证据底稿：**只留改变判断的已发生事实，按时序排列。推断与传闻补充层默认关闭，评分和必要答案仍在使用处可见。
- 调研、客户反馈、媒体转述均允许；标清来源与限制。检索摘要不能冒充已阅读全文，同一消息转载不能称多个独立证据。

## 9. 可读性规范：有明确的删减顺序

### 9.1 信息放在哪里

| 位置 | 保留什么 | 不放什么 |
| --- | --- | --- |
| 首屏 | 主张、矛盾、最近节点、总分与四个速览 | 多段结论、长算式、研究过程、版本对话 |
| 节点 | 事件、问题、答案、最核心证据、冲动 | 多跳背景、重复用途、无依据大概率 |
| 同敞口表 | 纯度中枢/范围、业务阶段依据、B/C/R | 大分部替身、整段模型、每股利多利空清单 |
| 折叠区 | 纯度参数、公司整体背景、评分依据、来源 | 用折叠掩盖与结论相反的关键信息 |
| 内部底稿 | 取数快照、全模型、MA、候选淘汰与修改记录 | 整体搬到正文 |

### 9.2 编辑时依次删

1. 重复结论、读者已看见的数字复述。
2. “原报告/原卡/与上一版相比”等依赖旧版本的过程文字。
3. “需要时展开/只供参考/保留原主标的”等无新增信息的说明。
4. 不改变主张、评分、节点、阶段或风险判断的背景。
5. 将长参数和计算移入一个统一折叠区。

压缩不能删掉估计标识、日期性质、来源限制和关键反证。正文判断通常1—2句；首屏摘要约80—140字；超出时先删重复，不强行缩字号。每个段落问：“去掉后，操盘手会失去什么具体判断信息？”答不出就删除或移入底稿。

## 11. 实现与工作流

1. 读取本规范与母版；锁定报告基准日、取价日、敞口约定和指定研究/主动推荐模式。
2. 主动推荐先过MA与下跌主因门槛。用公司披露、客户材料、协会、调研等搜集证据，补查延期、取消及已兑现信息。
3. 所有公司统一估计纯度，检查参数与合并范围；确定本敞口关卡与同一主张的C。
4. 对候选节点逐项执行第6节：多跳且缺桥的直接删除；保留的日期、问题、答案须能独立理解。
5. 用固定函数算B、总分、排序和显示；判断D/E及下行情景。源数据只维护一份，首屏、表格、规则和试算都引用它。
6. 按第9节压缩正文；复制母版生成独立HTML，核对本版不依赖历史文件里的数字或规则。
7. 执行下面的三道内容检查，再验数字、交互与版式。失败先修复，不以“待核验”标签掩盖未完成的核心比较。

内部数据至少包含：敞口约定、每家公司纯度三情景与参数来源、关卡证据、C主张与依据/反证、价格原始输入、MA记录、节点传导路径及取舍理由、行业PE样本和利润假设。

## 12. 交付前自查：三道必过的内容检查

### 12.1 节点传导检查

- [ ] 每个节点均满足“有关、有桥、有时点、有用途”。
- [ ] 无连续两个以上缺事实支持的商业假设；云技术→应用→需求→品牌订单等多跳背景已删除。
- [ ] 行业级节点明确只验证行业变量，不冒充公司订单证据。
- [ ] 无凑数会议、重复节点、虚构单日；未公布、弱于预期和真正反证分开处理。

### 12.2 敞口可比检查

- [ ] 纯度的产品范围、期间、分子/分母及会计范围一致；没有消费电子等大分部替身。
- [ ] 未披露值采用可复算情景，参数假设明示，未把模型结果写成已实现事实。
- [ ] 全表按中枢真实排序，范围共尺，重叠不硬判；无重复计算、超范围份额或未量产收入。
- [ ] 五关和C都对应本敞口；其他业务或公司整体数字只作背景，未给本敞口冒领高分。

### 12.3 表达与独立性检查

- [ ] 正文每段都影响具体判断，无重复摘要、模型墙、流程自述或空泛免责。
- [ ] 无“原报告/原稿/原卡/上一版”等对历史版本的依赖表达；现有来源、算式、参数和限制自足。
- [ ] 来源与关键反证没被删；事实、估计、假设和传闻能分辨。
- [ ] 首屏可快速读到主张、最近节点、B/C总分和敞口量级；详细模型只在对应折叠区。

### 12.4 计算、遗留字段与页面检查

- [ ] B按原精度公式分档，没主观改档；缺输入不补默认分。
- [ ] 首屏、同行表、规则、试算、meta描述和隐藏数据的B/C/总分一致；C当前级高亮正确。
- [ ] 全文（含隐藏层、aria、脚本和元数据）没有概率映射字段、先验联动表或旧样本硬编码。
- [ ] 90天首尾正确；H按52周高计算，未偷换高点或符号。
- [ ] 主动推荐有MA核验记录；指定研究未伪造正式准入结论。
- [ ] 来源ID唯一且可跳转；点击来源能展开父折叠。推断/传闻开关独立，默认关闭。
- [ ] 试算与固定评分同函数，非法输入不出Infinity/NaN；范围边界、总分条格数正确。
- [ ] 桌面/手机无文字遮挡或整页横溢出；展开模型仍可读，打印不丢关键信息。

内容三项通过后才能交付正式版本。工具自动检查不能代替逐节点、逐公司语义检查；不能承诺零错误，但必须实际执行这些检查。

## 14. 交给模型的简短入口

> 使用本规范和随附Version2.0 HTML，为指定个股或敞口制作报告。先锁定敞口比较约定；纯度允许间接证据估计，但全表必须同口径，关卡和C只评价该敞口。B严格按公式，不映射概率。逐节点检查传导，删除多处缺桥的长链背景；按信息层级压缩正文。独立交付一个HTML，交付前逐项完成§12自查。新研究重新取证，不能照搬样稿数值；主动推荐须满足全部准入门槛。
